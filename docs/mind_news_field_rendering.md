# MIND 新闻字段与页面渲染矩阵

`mind_news` 与 MIND `news.tsv` 一一对应，只有以下八个业务字段。页面展示所需的
`source_domain` 和 `categories` 是接口派生字段，不写回新闻主表。

| MIND / `mind_news` 字段 | 含义 | 信息流卡片 | 搜索结果 | 文章详情 |
|---|---|---|---|---|
| `news_id` | MIND 原生新闻编号 | 用作详情链接、事件和去重标识，不直接显示 | 用作详情链接和事件标识，不直接显示 | 用作路由和事件标识，不直接显示 |
| `category` | 一级分类 | 显示为分类标签 | 显示为分类标签 | 显示为主分类/标签 |
| `subcategory` | 二级分类 | 显示为分类标签 | 显示为分类标签 | 显示为分类标签 |
| `title` | 标题 | 显示 | 显示 | 显示为主标题 |
| `abstract` | 摘要 | 显示，卡片中限行 | 显示 | 显示完整摘要 |
| `url` | MIND 原始来源地址 | 通过详情页间接访问 | 通过详情页间接访问 | 显示为外部来源链接 |
| `title_entities` | 标题实体 JSON | 不显示 | 不显示 | 解析、去重并按人物/机构/地点/其他实体分组显示 |
| `abstract_entities` | 摘要实体 JSON | 不显示 | 不显示 | 与标题实体合并后分组显示 |

接口还会从 `url` 派生 `source_domain` 并直接显示来源域名；从 `mind_news_topic` 派生
`categories`，用于稳定的分类标签和推荐归因。这两个字段不是 MIND `news.tsv` 的新增列。
