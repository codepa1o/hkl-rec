# Friedman Gradient Boosting 阅读笔记

论文：Jerome H. Friedman, "Greedy Function Approximation: A Gradient
Boosting Machine", 2001.

## 一句话主线

Gradient Boosting 顺序增加小树：每一轮先计算当前模型对每条训练样本还应
怎样修正，再训练一棵回归树近似这些修正，最后把缩小后的树输出加到当前模型。

## 一轮训练

假设训练数据有 `N` 行，每行有项目定义的 16 个特征：

1. 前 `m-1` 棵树组成当前模型 `F_(m-1)(x)`。
2. 当前模型为每条样本产生一个 raw score，并转换为点击概率 `p_i`。
3. 对二分类交叉熵，样本 `i` 的负梯度可直观写成 `y_i - p_i`：
   - 点击但预测过低：负梯度为较大的正数，需要向上修正。
   - 未点击但预测过高：负梯度为较大的负数，需要向下修正。
   - 预测已经接近标签：负梯度绝对值较小。
4. 得到 `N` 个临时修正目标后，用原来的 16 个特征训练一棵新回归树：
   `x_i -> 负梯度_i`。
5. 树自动选择能最大幅度降低拟合误差的“特征 + 阈值”进行分裂。落入同一
   叶子的样本共享一个近似修正值。
6. 用 learning rate 缩小新树的影响，再更新模型：

   `F_m(x) = F_(m-1)(x) + learning_rate * tree_m(x)`

7. 根据更新后的预测重新计算负梯度，训练下一棵树。

## 叶子节点

叶子是决策路径的终点，保存这棵树对落入该区域样本的共同输出。

教学例子：一个叶子内的负梯度为 `+0.8、+0.6、+0.7`，在平方误差直觉下，
叶子可用平均值 `+0.7` 近似它们。新样本只要满足相同分裂规则并落入该叶子，
也会得到约 `+0.7` 的树输出。

树分裂的目的，是把修正需求不同的样本分开。例如将正负梯度分到不同叶子，
会比让所有样本共享接近零的输出更准确。

## 学习率

项目设置 `learning_rate=0.05`。若新树叶子输出 `+0.7`，这一轮实际只给
raw score 增加：

`0.05 * 0.7 = 0.035`

较小的 learning rate 降低单棵树的话语权，通常更稳健，但需要更多 boosting
轮次。

## 项目映射

`scripts/train_eval_mind.py` 当前使用：

- `LGBMClassifier(objective="binary")`：训练目标是点击二分类。
- `n_estimators=120`：顺序增加 120 棵修正树。
- `learning_rate=0.05`：缩小每棵新树的贡献。
- `num_leaves=31`：每棵树最多 31 个叶子。
- `min_child_samples=50`：叶子至少包含约 50 条训练样本。

线上将模型输出作为 `final_score` 降序排列。训练任务是二分类，业务用途是
候选排序。

## 面试话术

> 我们使用的是 Gradient Boosting，不是 Random Forest。每一轮先基于当前
> 模型为每条样本计算负梯度；在点击二分类中，可以把它直观理解为真实标签
> 与当前点击概率之差。然后训练一棵回归树，根据 16 个特征近似这些修正目标。
> 落入同一叶子的样本共享一个叶子修正值，再乘以 0.05 的 learning rate 加到
> 当前 raw score。更新后重新计算负梯度，顺序训练下一棵树，最终用模型分数
> 对候选文章排序。

## 易混点

- 16 是每条样本的特征数，不是训练样本数。
- 每轮有多少条训练样本，就会计算多少个负梯度。
- 负梯度是本轮临时学习目标，不会替换真实点击标签。
- raw score 是初始基准分与已有树输出的累加，不是最终概率。
- learning rate 控制新树贡献，不控制树深度，也不是抽取 5% 数据。
