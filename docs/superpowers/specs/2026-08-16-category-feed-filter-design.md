# 新闻分类侧栏与个性化筛选设计

## 目标

在桌面端左侧栏展示 MIND-small 数据中的全部 18 个一级新闻分类，并提供“全部新闻”入口。用户选择一个分类后，信息流只返回该分类的新闻，同时继续使用当前用户画像进行召回、打分与排序。新闻标题和正文保持原语言，分类名称使用中文。

本功能只处理一级分类，不展示 270 个二级分类，也不把分类点击等同于关键词搜索。

## 已确认的交互

- 左侧栏采用单列纵向列表，分类区域独立滚动。
- 列表顶部固定“全部新闻”，其后展示全部 18 个一级分类。
- 当前分类具有明确的选中状态。
- 页面地址使用首页查询参数保存状态，例如 `/?category=sports`；“全部新闻”使用 `/`。
- 切换用户画像时保留当前分类；切换分类时重新开始该分类的信息流会话。
- 分类内继续执行当前的个性化召回和排序，而不是改为统一热度或时间排序。

## 分类数据来源

后端新增 `GET /categories`，从 `news.category` 聚合实际可用的一级分类，返回原始分类键和新闻数量：

```json
{
  "items": [
    { "key": "sports", "news_count": 19368 }
  ]
}
```

接口按 `news_count DESC, key ASC` 排序，不在后端保存中文显示文案。前端复用统一中文映射将分类键转换为“体育”等标签，无法识别的键保留原文。这样侧栏不会依赖写死的三项列表，也能随实际目录变化。

数据集当前共有 18 个一级分类：`autos`、`entertainment`、`finance`、`foodanddrink`、`games`、`health`、`kids`、`lifestyle`、`middleeast`、`movies`、`music`、`news`、`northamerica`、`sports`、`travel`、`tv`、`video`、`weather`。

## 后端筛选设计

`GET /feed` 新增可选的 `category` 查询参数。未提供时保持现有行为；提供时，服务在所有候选通道中只允许 `news.category` 与参数完全相等的新闻：

- 用户画像主题召回；
- 最近搜索主题召回；
- ALS 协同召回；
- 探索候选；
- 热门或新鲜内容补充；
- 未浏览目录补充；
- 赞助内容。

过滤必须进入候选查询或候选补充阶段，不能只在最终返回前删除不匹配结果，否则会导致页面数量不足、游标提前结束或赞助内容跨分类泄漏。候选进入现有特征构建、模型打分、MMR 和固定广告位混排后，排序算法保持不变。

分类参数会进入信息流请求的幂等上下文和分页会话。后续页必须携带与首屏相同的分类；游标对应的会话与请求分类不一致时返回参数错误，防止不同分类共享已浏览集合或分页状态。不存在的分类返回 `422`，不启动信息流请求。

## 前端数据流

左侧栏加载 `/categories`，渲染“全部新闻”及接口返回的 18 个分类。分类链接更新首页的 `category` 查询参数，不再跳转到搜索页。

`FeedPage` 从地址读取分类键，并把它加入：

- 首屏 `getFeed` 请求；
- 后续无限滚动请求；
- 稳定请求 ID 的逻辑键；
- effect 依赖和信息流会话重置条件。

分类改变时清空旧页、游标、加载错误与当前信息流用户标记，再发起新的分类信息流请求。旧请求返回后不得覆盖新分类状态。地址中的未知分类会显示中文错误状态，并提供返回“全部新闻”的入口。

## 组件边界

- `CategoryList`/分类接口类型：描述分类键及新闻数。
- `LeftSidebar`：负责加载、显示、滚动和选中态，不负责过滤新闻数组。
- `FeedPage`：负责从 URL 获取分类、管理分类对应的信息流会话及分页。
- 后端分类仓储方法：列出分类并验证分类存在性。
- 后端信息流仓储：把分类约束传入所有召回和补充通道。

## 错误与空状态

- 分类列表加载失败：侧栏保留“全部新闻”，显示简短的分类加载失败提示。
- 有效分类暂无结果：中间栏显示“该分类暂无推荐新闻”。
- 无效分类：显示“该新闻分类不存在”，并提供“查看全部新闻”。
- 加载更多失败：保留已经显示的分类结果，允许重试，不混入其他分类。

## 测试范围

后端测试覆盖：

- 分类接口返回实际存在的全部一级分类及数量；
- 分类参数只返回完全匹配的新闻；
- 分类筛选后仍使用个性化得分排序；
- 初始页和后续游标页不跨分类、不重复；
- 分类不一致的游标请求被拒绝；
- 赞助和兜底候选不会跨分类；
- 不传分类时现有信息流行为保持不变。

前端测试覆盖：

- 左侧栏渲染“全部新闻”和接口分类，并显示中文名称；
- 分类链接、选中态及独立滚动结构正确；
- 首屏和加载更多请求都携带分类；
- 切换分类会重置信息流，迟到响应不会污染新分类；
- 分类接口失败、无结果和无效分类状态使用中文。

## 非目标

- 不展示或筛选 270 个二级分类；
- 不增加多分类同时选择；
- 不改变现有个性化模型、特征权重或训练流程；
- 不把分类选择记录为搜索意图；
- 不在本次功能中重新设计移动端导航。
