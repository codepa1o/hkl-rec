# 搜索框操作区设计

## 目标

在现有中文搜索框右侧增加清空和搜索操作，让用户能够明确提交搜索，并在不刷新整个页面的情况下清空关键词、建议和搜索结果。

## 界面结构

- 左侧保留搜索图标和文本输入区。
- 输入框有内容时，在输入区右侧显示“×”清空按钮；空内容时不显示。
- 最右侧增加带“搜索”文字的主操作按钮，并与输入区组成一个连续的搜索控件。
- 搜索按钮在关键词为空或仅包含空格时禁用。
- 沿用现有颜色、边框、圆角和主题变量，不引入新的视觉体系。

## 交互行为

- 点击“搜索”或按 Enter，均使用去除首尾空格后的关键词执行现有搜索跳转。
- 点击“×”后立即清空输入值、搜索建议和建议面板，并取消尚未触发的建议请求。
- 如果当前位于搜索结果页，清空时导航到无查询参数的 `/search`，使结果区回到初始提示状态；不进行浏览器整页刷新。
- 如果当前位于其他页面，清空只重置搜索框本身，不改变当前页面。
- 清空完成后焦点返回输入框，方便继续输入。
- 选择搜索建议时继续沿用现有精确搜索行为。

## 可访问性

- 清空按钮使用中文可访问名称“清空搜索内容”。
- 搜索按钮使用可见文字“搜索”。
- 保留 Enter 键提交；所有操作均可通过键盘聚焦和触发。
- 禁用状态同时使用原生 `disabled` 属性表达。

## 测试范围

- 有内容时显示清空按钮，空内容时隐藏。
- 点击清空按钮会清空输入、关闭建议并保持输入焦点。
- 在搜索结果页清空会导航到 `/search`，其他页面不发生导航。
- 点击搜索按钮与按 Enter 使用同一搜索规则。
- 空白关键词不会搜索且搜索按钮处于禁用状态。
- 现有建议选择行为保持不变。

## 非目标

- 不刷新浏览器页面。
- 不修改搜索接口、搜索算法或建议接口。
- 不增加搜索历史、语音搜索或快捷键系统。
